// Browser
Web Client > API Gateway: API calls with token
Web Client <> WebSocket API: live status
Web Client --> Object Store: upload and download files directly

// Services
API Gateway > Auth Service: sign in, refresh, sign out
API Gateway > DocBeam API: uploads, jobs, status, downloads
API Gateway > Document Platform: browse teams and folders
Auth Service > Databases
DocBeam API > Databases
Document Platform > Databases
Document Platform > Platform File Store: store delivered files

// Upload checks
Object Store > Upload Checks: file stored
Upload Checks > Object Store: scan, tag clean or delete infected file
Upload Checks > Databases: mark file verified or refused

// Sending
DocBeam API > Job Queue: one message per job
Job Queue > Fan-out Lambda
Fan-out Lambda > Task Queue: one message per delivery
Task Queue > Delivery Lambda
Delivery Lambda > Document Platform: deliver file
Delivery Lambda > WebSocket API: push status

// Safety nets
Job Queue --> Failure Handling: repeated failures
Task Queue --> Failure Handling: repeated failures
Upload Checks --> Failure Handling: repeated failures
Sweeper > Job Queue: re-send stuck jobs
Failure Handling --> Alarms
