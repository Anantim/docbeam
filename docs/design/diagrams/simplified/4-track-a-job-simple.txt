title Track a Job (Simplified)
autoNumber nested

User [icon: user]
Web Client [icon: react, color: blue]
WebSocket API [icon: aws-api-gateway, color: green]
DocBeam API [icon: aws-ecs, color: green]
Delivery Lambda [icon: aws-lambda, color: green]

User > Web Client: Open Status
Web Client > DocBeam API: Everything I can see (filters: status, sender, sent, team)
DocBeam API --> Web Client: Jobs with counts, 20 at a time (more as the user scrolls)

User > Web Client: Open one job in the side panel
Web Client > WebSocket API: Subscribe (checked: sender or same team)
Web Client > DocBeam API: At the same time, load the job and its first deliveries
WebSocket API --> Web Client: Subscribed (a job still running is read once more now)
DocBeam API --> Web Client: All deliveries for the sender, own teams' for others

loop [label: each delivery retries or finishes, icon: repeat] {
  Delivery Lambda > WebSocket API: New status (Retrying, Completed or Failed)
  WebSocket API --> Web Client: Row and totals update live (reasons on hover; cancelled shown grey, apart from failures)
}

opt [label: connection drops] {
  Web Client > WebSocket API: Reconnect and subscribe again
  Web Client > DocBeam API: Reload once to catch up
}

opt [label: sender presses Retry or Cancel (icons)] {
  Web Client > DocBeam API: Retry failed, or cancel waiting deliveries
  DocBeam API --> Web Client: Updated job
  DocBeam API > WebSocket API: Tell every open page
  WebSocket API --> Web Client: Others reload the deliveries
}
