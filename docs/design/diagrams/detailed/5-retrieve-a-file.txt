title Retrieve a File (Detailed)
autoNumber nested

// Actors
User [icon: user]
Web Client [icon: react, color: blue]
API Gateway [icon: aws-api-gateway, color: green]
DocBeam API [icon: aws-ecs, color: green]
DocBeam DB [icon: aws-rds, color: orange]
Document Platform [icon: aws-ecs, color: green]
Platform DB [icon: aws-rds, color: orange]
Object Store [icon: aws-s3, color: orange]

User > Web Client: Open a job and click Preview or Download on a file
Web Client > API Gateway: Request a link (mode: download or preview) with JWT
API Gateway > DocBeam API: Validate JWT and forward

opt [label: mode is not download or preview] {
  DocBeam API --> Web Client: 400 VALIDATION_ERROR, no URL created
}

DocBeam API > DocBeam DB: Look up file, its job, the sender and the teams it was delivered to (completed deliveries)

opt [label: caller is not the sender] {
  DocBeam API > Document Platform: Which teams is the caller in? (service token from startup, answer cached 60 s)
  Document Platform > Platform DB: Read the caller's teams
  Document Platform --> DocBeam API: Team IDs
}

alt [label: sender, or file delivered (completed) to the caller's team, within 33-day storage] {
  DocBeam API > DocBeam DB: Write download.issued audit event (mode; for anyone but the sender, team = lowest-id matching team, every matching team in the detail)
  DocBeam API > DocBeam API: Sign GET URL locally (one file, 2 min; attachment under the original name, or inline with the stored type for a preview)
  DocBeam API --> Web Client: Return the URL with the file's name, type and size (from its record)
  Web Client > Object Store: Fetch the file with the URL
  Object Store > Object Store: Check signature, expiry and the clean scan tag
  Object Store --> Web Client: File bytes
  Web Client > Web Client: Download: save through a hidden link, count down the link's 2 minutes. Preview: PDF and images straight from the link, DOCX and XLSX (up to 50 MB) as a read-only page in a sandboxed frame
}
else [label: allowed, but the file is past its 33-day storage period (checked only after access passes)] {
  DocBeam API --> Web Client: 410 FILE_EXPIRED, no URL created
}
else [label: bad id, file missing, in no job, not scanned clean, or not delivered to the caller's teams] {
  DocBeam API --> Web Client: 404 Not found (same answer for all), no URL, no audit event
}
